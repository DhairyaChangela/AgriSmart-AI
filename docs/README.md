## Conventions

- One idea per page. Short paragraphs, real headings.
- Status is always explicit: **Current**, **Planned**, or **Future**.
- No invented metrics, datasets, testimonials, or screenshots.
- Diagrams use Mermaid so they render directly on GitHub.
