# Assets

Future home of visual material. This folder is intentionally empty — no placeholder images are committed.

## Planned layout

| Path                 | Contents                                              |
| -------------------- | ----------------------------------------------------- |
| `screenshots/`       | Real app screenshots, captured from working builds    |
| `diagrams/`          | Exported architecture and pipeline diagrams           |
| `agri-bot/`          | AgriBot character states and usage notes              |
| `branding/`          | Logo, wordmark, and color usage (when finalized)      |

## Rules

1. Only real artifacts — never mockups presented as product screenshots.
2. Screenshots must come from the current build; stale captures are removed.
3. Keep originals small and web-friendly (PNG/JPG, no multi-MB files).
4. Diagrams stay as Mermaid source in docs first; exports are copies, not originals.
