## Rules

1. Only real artifacts — never mockups presented as product screenshots.
2. Screenshots must come from the current build; stale captures are removed.
3. Keep originals small and web-friendly (PNG/JPG, no multi-MB files).
4. Diagrams stay as Mermaid source in docs first; exports are copies, not originals.
